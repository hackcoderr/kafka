A PRACTICE PATH

Build intuition one experiment at a time.

1 · Topics & partitions

Create a 3-partition topic. Send events with three keys. Which partition does each key consistently choose?

2 · Consumer groups

In Kafka UI, create two consumers in one group and observe partitions being shared—not duplicated.

3 · Offsets & replay

Preview a topic here, then reset a consumer-group offset in Kafka UI. Contrast a replay with a new group.

4 · Replication

Create a topic with replication factor 2. Stop one broker and see what remains available. Restore it afterward.
