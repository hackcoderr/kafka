A topic is split into partitions. Each partition is an append-only ordered log. A key chooses a partition; an offset is a record’s position within it.

QUICK RECALL

The words you need

TopicA named stream of records.
PartitionAn ordered, append-only log inside a topic.
OffsetA record position inside one partition.
KeyRoutes records consistently to a partition.
GroupConsumers sharing a topic’s partitions.
ReplicaA copy of a partition on another broker.

WHEN YOU ARE READY

Design it like a real system.

For every production topic, decide the event contract, key, partition count, retention, schema compatibility, failure path, access controls, and the signal that tells you it is healthy.
